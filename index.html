ツールの使い方

1基本の流れ（3ステップで1ページ完成）

いちばん手軽なのは、画面右上の ★ かんたん作成 です。画像を入れてコマの数を選び、「この内容で作る」を押すだけで1ページできます。左の①〜④でも同じことができます。

  1. ベースにする画像を入れる … 左上「① ベースにする画像」に、生成済みの画像をドロップします（複数可）。最初に入れた画像が ★ ベース（ストーリーの主軸） になります。☆ を押すとベースを変えられ、✕ で外せます。同じ画像は二重に入りません。
  2. コマ割りを選ぶ … 「② コマ割りテンプレート」から好きな形を選びます。
  3. 「④ 実行」を押す … コマは空のままでOK。文章AIが画像のプロンプトをジャンル分けし、画像そのものとプロンプトの両方からストーリーを考え、画像を合うコマに配置して、残りのコマだけを生成します。

2コマの内容を自分で決める

  • 右の「このコマ」タブのコマ一覧で、各コマの「生成したい内容」を日本語で書けます（例: パンを咥えて走る少女）。空欄のコマは、実行時にAIが考えます。
  • ベースの画像を好きなコマへ直接ドラッグすると、そのコマに固定して使います。
  • 全コマで使うモデルやプロンプトは「全コマ共通」タブで設定します。

3コマの形を変える

  • コマを押して選び、角の □ をドラッグすると大きさが変わります。
  • 区切りの ○ を押すと、その区切りだけ「隙間 ⇔ 線」の切り替えや斜めにできます。区切りを削除すると両側のコマが結合します。
  • 「✂ 2点で分割」でコマの辺を2か所クリックすると、その線で分けます（Esc で中止）。
  • Shift / Ctrl を押しながら押すと複数選択でき、隣り合うコマを「結合」できます。

4コマの中の画像を調整する

  • 画像が入ったコマをダブルクリックすると調整モードになります。ドラッグで移動、四隅をつまむと反対側の角を基準に拡大・縮小します。
  • 字コンテ: コマごとに画角・アングル・最初に見せるもの・行動や反応・音・役割を決める表です。空欄のコマは、生成するときに文章AIが先に字コンテを書いてからプロンプトを作ります。
  • ネームのレビュー: 生成する前に、文章AIが編集者の目で計画を見直し、問題点と直し方を出します（「反映」でそのまま直せます）。
  • 画像チェック（MOSS）: 生成後に文章AIが画像を見て、文字の誤り・余計な文字・キャラのずれを確かめ、サムネイルに ✓ / ! を付けます。
  • 文字の点検（吹き出しタブ）: 「。」を使わない・「、」は20字以上だけ・禁則・読む順・はみ出しなどを点検し、まとめて直せます。
  • 「コマ編集」中に吹き出しをダブルクリックすると「吹き出し」モードに切り替わり、そのままセリフを編集できます。「吹き出し」モード中にコマ（吹き出しのない所）をダブルクリックすると「コマ編集」に戻ります。
  • 反転・90°回転・カラー / モノクロは、左の「③ コマの編集」から。画像が見えなくなったら「画像をコマの中央へ」。

5吹き出し・セリフ

  • 「＋ 吹き出しを追加」を押すか、右の「吹き出し」タブでセリフを入力すると吹き出しが追加されます。
  • 吹き出しもしっぽの先もドラッグで動かせます。形・文字の大きさ・縦書き / 横書きは「吹き出し」タブで変えます。

6生成をやり直す

  • コマを選んで「このコマを再生成」。複数選んでまとめて再生成もできます。ベースの画像が入ったコマは、選んだときだけ作り直します。
  • 生成した画像はすべて残り、コマの詳細から押して切り替えられます。

7保存・書き出し・投稿

  • プレビューの下の「作業データを保存（JSON）」で作業中のデータを保存し、上の「開く」で続きから。「ページを画像で書き出す（PNG）」で1ページの画像に。
  • 生成後に微調整するときは、プレビューの下で「生成画像を薄く」か「コマ・吹き出しを薄く」を選んでバーで濃さを変えるか、「画像を隠す」で画像を隠します（隠しているときは、コマと吹き出しを透過せずに表示します）。書き出し・投稿には影響しません。
  • 「Prompt Reel に投稿」で、ページを1枚目、各コマの画像を差分として投稿画面へ渡します。
  • ショートカット: Ctrl+Z 戻る ／ Ctrl+Shift+Z やり直す ／ Delete 削除

8MOSS-Image でページを1枚で生成する

  • 左上「① ベースにする画像」には、★ベースの画像を元の縦横比のまま大きく表示し、その下に読み込んだ画像を正方形のサムネイルで並べます。
  • いちばん手軽な使い方: 左上の「① ベースにする画像」に画像をドロップ（または Ctrl+V で貼り付け）して、右の「MOSS」タブを開き、左下の「④ MOSSで生成」を押します。文章AIが空欄の部分（ストーリー・コマ割り・各コマの内容・字コンテ・セリフ・英語の説明）だけを考えてから、MOSS-Image で1ページを生成します。「コマ割り」「コマの内容」「セリフ・文字」はそれぞれ、おまかせにするかをスイッチで選べます。
  • 「キャラクター指定」（MOSS タブの「紙面と画風」、全コマ共通タブ）に、生成したい人物の名前と見た目・服装・性格などを書くと、その人物で漫画を作ります。1人目が主人公で、「＋ 登場人物を追加」で増やし、✖ で外せます。日本語でOKです。
  • 「漫画を再現する」をオンにして★ベースに漫画のページを入れると、文章AIがコマ割り・各コマの絵・セリフ（文字と位置）を読み取り、同じページを描き直します（MOSS タブでは「④ MOSSで生成」、全コマ共通タブでオンにしたときは「④ 実行」）。キャラクター指定があれば、その人物に置き換えます。画像を読める文章AIが必要です。
  • コマ割りテンプレートは全92種類です。「テンプレート」の欄で、コマ数・斜め・演出などに絞り込めます。サムネイルにマウスを乗せると、向いている場面が出ます。
  • 「コマ」を「なし（1枚絵）」にすると、ページ全体を1枚の絵として生成します（ポスター・CDジャケット風など）。「1枚絵の種類」でポスター・映画ポスター・雑誌の表紙・CDジャケット・小説の表紙・イラストを選ぶと、文章AIがタイトル・キャッチコピー・クレジットなどの文字も考えます。用紙は B5・A4・A3・正方形・カスタム（幅と高さを自由に）から選べます。
  • セリフは「MOSS」タブの「セリフ・文字（コマごと）」で、コマごとに追加・編集できます。種類（吹き出し・叫び・心の声・ナレーション・効果音・枠なしテキスト・タイトル・キャッチコピー・クレジット・ラベル）、書体（筆文字も）、色、縦書き / 横書き、大きさ、位置（おまかせ・右上など・ドラッグした位置）を決められます。
  • 右の「MOSS」タブを開いているあいだは、左下のボタンが「④ MOSSで生成」になり、ページ全体を1枚で生成します（接続先は SD WebUI（Forge Neo）＋ MOSS-Image 拡張機能）。「このコマ」「全コマ共通」タブに切り替えると、コマごとの生成（④ 実行）に戻ります。
  • コマの形・位置、吹き出しのセリフ（縦書き / 横書き・書体・形）、各コマの「生成したい内容」と画風が、そのまま MOSS 用のレイアウトJSON（bbox 付き）になります。英語の説明は文章AIが書きます。
  • Checkpoint・Text Encoder・VAE・LoRA は MOSS 専用に選びます。SD WebUI につながったとき、空欄なら Forge で選んでいるもの（または名前に moss を含むもの）を自動で入れます。LoRA は一覧から選び、「moss を含むものだけ」で絞り込めます。
  • 文字は「MOSSが描く」か「アプリで重ねる」を選べます。生成した画像はそのまま表示・書き出し・投稿します（「アプリで重ねる」や「コマの外側を塗る」をオンにしたときだけ、Stillmange で文字の重ね描き・塗りつぶしをします）。
  • 「MOSS」タブのいちばん上の「漫画の方針」に、この漫画への要望（話の筋・雰囲気・画風・タイトルなど）を書きます。色・文字の扱い・おまかせのスイッチ・「コマの外側をページの色で塗る」もここにまとめています。画風はコマごとの内容の「画風」欄に、コマのあり／なしは左の「コマ」で決めます。
  • 送る前のJSONは「MOSS に送るJSONを確認・手直し」で見られ、手で直してそのまま生成することもできます。
  • 生成したページのサムネイルを押すと、その画像のプロンプトと設定を読み込みます。そのまま生成すると同じプロンプトで再生成、「MOSS に送るJSON」を書き換えて生成するとその内容で生成します。コマ・吹き出しの変更を反映するときは「コマ・吹き出しから作り直す」を押します。おまかせのスイッチがオンでも、自分で書いた指示とセリフは優先して残します。
  • 生成した画像を表示しているときに上の「吹き出し」を押すと、その画像を作ったときの吹き出しを薄く重ねて表示します（「コマ編集」に戻すと消えます）。ドラッグで移動、セリフを書き換えて「④ MOSSで生成」を押すと、文字の部分だけをいまの吹き出しで作り直して生成します。
  • 生成ボタンを押すと、英語の説明に空欄があればその部分だけを、いま入力されている日本語の内容やストーリーから文章AIが書いてから生成します（書いてある部分はそのまま）。コマの内容を変えたいときは、そのコマの英語の欄を消して日本語を書き換えて生成します。
  • 「連続生成（枚）」を2以上にすると、シードを変えて続けて生成します。生成したページは、ページの下にサムネイルで並び、押すと切り替わります（コマ割りを見ながら調整するときは、プレビュー下の「画像の濃さ」「画像を隠す」を使います）。
  • 白黒のときは、生成した画像を Stillmange で完全なグレースケールに変換します。ベース画像のキャラクター名・作品名は、全体の説明と各コマの説明に入ります。「コマの外側をページの色で塗る」をオンにすると、生成後にコマの外を黒（または白）で塗ります。
  • 生成設定は MOSS-Image のおすすめ（Euler・MOSS・50 ステップ・CFG 3・1.5MP、Base モデルはおすすめのネガティブ）が基本です。「おすすめ設定に戻す」でいつでも戻せます。

はじめて使うときは「設定」から、画像生成（WebUI / ComfyUI）と文章AI（ローカルLLM）の接続を確認してください。

設定

はじめに

このページはブラウザから、あなたのPCの Stable Diffusion WebUI（A1111 / Forge）か ComfyUI に直接つなぎます。画像や設定が外部のサーバーに送られることはありません。最初の1回だけ、次の準備をします。

1. 「ローカル ネットワーク上のデバイスへのアクセス」を許可する

初めて接続するときにブラウザに確認が出たら「許可」を押します。ブロックしたときは、アドレスバー左のアイコン →「サイトの設定」→「ローカル ネットワーク アクセス」を「許可」にして再読み込みします。Chrome か Edge で開いてください。

2. Stable Diffusion WebUI（A1111 / Forge / Forge Neo）を使う場合：拡張機能 web-app-cors を入れる

接続を許可する小さな拡張機能を入れます（このページのアドレス だけを許可し、使えるのも画像生成やモデル一覧など、このアプリが使う窓口だけです）。画像生成用のAPIもこの拡張機能が有効にするので、起動オプションは空のままで使えます。

  1. ZIP を WebUI の extensions フォルダに展開し、extensions\web-app-cors\scripts\web_app_cors.py となるようにします（web-app-cors フォルダが二重にならないよう注意）。
    Stability Matrix の場合: Data\Packages\（パッケージ名。例: forge-neo）\extensions
  2. 起動オプション（Stability Matrix なら「Extra Launch Arguments」、それ以外は webui-user.bat の COMMANDLINE_ARGS）には、何も書く必要はありません。
  3. WebUI を停止 → 起動し直します。ログに [web-app-cors] v4 allowed origins: … と出れば読み込まれています（v1〜v3 と出る場合は古い版なので、ダウンロードし直して入れ替えてください。v1 は LoRA の一覧が出ない原因に、v3 の ComfyUI 用は生成の進み具合が出ない原因になります）。
  4. ブラウザで を開き、{"ok":true, …, "api":true} と出れば準備完了です。

ログに could not enable API と出た場合は、起動オプションに --api を足してください。ログに Exception in thread … (webui_worker) が出ている場合は、起動途中で止まっているため拡張機能が読み込まれません。エラーに名前が出ている拡張機能（例: sd-webui-ar）を外してください。

2'. ComfyUI を使う場合：カスタムノード web-app-cors を入れる

接続を許可する小さなカスタムノードを入れます（このページのアドレス だけを許可し、カスタムノードの追加などの窓口は断ります）。「設定」→「画像生成の接続」で ComfyUI を選んでください。

  1. ZIP を ComfyUI の custom_nodes フォルダに展開し、custom_nodes\web-app-cors\__init__.py となるようにします（web-app-cors フォルダが二重にならないよう注意）。
    Stability Matrix の場合: Data\Packages\ComfyUI\custom_nodes
  2. 起動オプションに --enable-cors-header が入っていたら外します（付けたままだと、ほかのサイトからも接続できてしまいます）。起動オプションは空のままで使えます。
  3. ComfyUI を停止 → 起動し直します。ログに [web-app-cors] v4 allowed origins: … と出れば読み込まれています（v1〜v3 と出る場合は古い版です）。
  4. ブラウザで を開き、{"ok":true, …} と出れば準備完了です。

3. 接続を確認する

画像生成の接続

使う画像生成のソフトと URL です。変えるとすぐに保存されます。

生成した画像は、各ツールの標準の場所・名前で保存されます（SD WebUI: outputs/txt2img-images/日付フォルダ、ComfyUI: output/ComfyUI_00001_.png など）。

文章AI（LLM）

コマごとの大まかな指示（「町の風景」「顔のアップ」など）を、画像生成用のプロンプトに書き直すローカルLLMです。OpenAI 互換サーバー（LM Studio・Bionic・KoboldCpp・Ollama・llama.cpp など）が使えます。サーバーURLの下の候補を押すと切り替わります（緑の点は起動中）。ページを開いたとき・このページに戻ってきたとき・上部の「更新」を押したときに起動中のものを探します。変えるとすぐに保存されます。

文章AIのサーバーを起動してから押します

CORS（このページからの接続）を許可する

LM Studio / Bionic: サーバーを起動し「Enable CORS」（Bionic は「CORS」）をオン。Ollama: 環境変数 OLLAMA_ORIGINS にこのページのURL（）を設定して起動し直します。KoboldCpp: 設定は不要です（最初から許可されています）。画像を読ませるときは、起動時に mmproj ファイルを指定します。
